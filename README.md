# ShadowNotes 🕶️

Анонимные саморазрушающиеся заметки.  
Без аккаунтов. Без логов. Без истории.

ShadowNotes — это минималистичный сервис для передачи сообщений,
которые должны быть прочитаны **один раз** и **исчезнуть навсегда**.

---

## ✨ Идея

Иногда сообщение не должно:
- сохраняться
- пересылаться
- попадать в историю
- становиться «скриншотом навсегда»

ShadowNotes создаёт **одноразовый момент**:
ты пишешь → передаёшь ссылку → сообщение исчезает.

---

## 🔐 Принципы

- ❌ Нет регистрации
- ❌ Нет аккаунтов
- ❌ Нет базы данных
- ❌ Нет логирования содержимого
- ❌ Нет восстановления

- ✅ Самоуничтожение по времени (TTL)
- ✅ Самоуничтожение после прочтения
- ✅ Опциональная защита паролем
- ✅ Минимум кода, минимум состояния

---

## 🧠 Как это работает (концептуально)

- Каждая заметка существует только в памяти сервера
- У заметки есть срок жизни или флаг удаления после чтения
- После удаления данные **невозможно восстановить**
- Если ссылка потеряна — заметка потеряна

Это осознанное ограничение, а не баг.

---

## ⚠️ Важно

ShadowNotes **не предназначен** для:
- долгосрочного хранения информации
- передачи критически важных данных
- обхода законов или обязательств

Это инструмент для личных, мимолётных сообщений.
Используйте с пониманием его природы.

---

## 📦 Минимализм как принцип

Проект намеренно остаётся простым:
- маленький размер
- прозрачная логика
- отсутствие лишних зависимостей

Чем меньше система — тем меньше ей можно навредить.

---

## 🪞 Почему код открыт

Открытый код здесь — это не приглашение к форкам,  
а способ показать отсутствие скрытой логики.

Если вам важно доверие — посмотрите код сами.
